# Reproducible analysis

The finished project package includes `segment_metrics.csv` with detailed group sizes, buyer counts, and purchase rates across customer attributes.

Key verified results:

| Segment | Purchase rate |
|---|---:|
| All customers | 48.1% |
| Commute 2–5 miles | 58.6% |
| Commute over 10 miles | 29.7% |
| Ages 31–53 | 54.3% |
| No cars | 61.1% |
| Pacific region | 58.9% |

Purchase rate is calculated within each subgroup, not as a percentage of all bike buyers. These are descriptive findings only.
