# Data dictionary

| Field | Meaning |
| --- | --- |
| Customer ID | Unique customer identifier |
| Marital Status | Recorded relationship status |
| Gender | Recorded gender category |
| Income (units) | Reported income; currency and period not documented |
| Children | Number of children |
| Education | Highest reported education category |
| Occupation | Occupation group |
| Home Owner | Yes / No |
| Cars | Number of cars owned |
| Commute Distance | Categorical travel-distance band |
| Region | Customer region |
| Age | Age in years |
| Age Group | Derived 25–30, 31–53, and 54+ segments |
| Purchased Bike | Yes / No target |
| Purchase Flag | Derived binary indicator (Yes = 1, No = 0) |

**Data grain:** one customer per cleaned record. The educational dataset does not support financial revenue, causal claims, or real-world campaign lift.
